# 두 목록의 어긋남 — 보행노인 vs 보행자 사고다발지역 공간 대조

**한겨레 × 숲과나눔 「AI와 함께하는 교통문제 해결을 위한 데이터 분석 공모전」 제출 코드 (팀 폴라앱)**

데모: **https://link.chlee.dev/gap2.html**

## 무엇을 하는가

도로교통공단은 같은 현상(보행자 사망·중상)을 **두 개의 고시 목록**으로 따로 관리한다.

| 목록 | 대상사고 | 기간 | 반경 | 임계값 |
|---|---|---|---|---|
| 보행자 사고다발지역 | 보행자 사망·중상 | 최근 3년 | 100m | **7건 이상** |
| 보행노인 사고다발지역 | **65세 이상** 보행자 사망·중상 | 최근 3년 | 100m | **5건 이상** |

기간·반경·중증도가 동일하고 **임계값만 다르다.** 이 코드는 두 목록의 좌표를 겹쳐
**어느 쪽에만 있는 지점**을 센다. 예측하지 않는다 — **대조**한다.

## 결과 (2026년 고시 기준)

- 노인 291곳 · 보행자 418곳 · 겹침 198곳 · **노인 목록에만 있는 지점 93곳**
- 그 93곳 중 **92곳(98.9%)이 사고 5~6건 구간** — 어긋남은 임계값이 만든 구조다
- 93곳 합계 사망 25명 · 중상 457명
- 전용 비율 추세: 23.4%(2022) → **32.0%(2026)**

## 실행

```bash
python3 src/analyze.py          # 전체 분석 → data/result.json
python3 src/export_demo.py      # 데모용 지점 배열 생성
python3 src/build.py            # 단일 HTML 데모 빌드
python3 src/make_figs.py        # 보고서용 SVG 4장
```

Python 3.12 · **외부 의존성 없음**(표준 라이브러리만). 난수·학습 파라미터가 없어
같은 입력에 항상 같은 결과가 나온다.

| 보행자 교통사고 다발지역 | 한국도로교통공단 | 공공데이터포털 → 제공처 | https://www.data.go.kr/data/15105289/fileData.do |

기준시점 2026년 고시본 · 주요 변수: 지점 좌표, 사고건수, 사상자·사망·중상자 수, 시도시군구명
이용조건: 각 제공기관의 공공데이터 이용약관. **크롤링·계정 우회 없이** 공식 개방 경로만 사용했다.
